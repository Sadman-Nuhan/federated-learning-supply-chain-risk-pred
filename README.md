# federated-learning-supply-chain-risk-pred
Formulated First-Order Personalized Federated Averaging and compared with standard Federated Averaging and local models for late-delivery risk prediction on the DataCo supply chain dataset (23 Order Region silos). All the models use the same ANN structure.
For downloading the file and loading into the script please follow "https://www.kaggle.com/code/cheukhangtse/dataco-supply-chain-analysis/input".
